ABOUT ME

Saya ELA BOMEN HIA, saat ini bekerja sebagai Control Room Officer di G4S yang ditempatkan di lingkup industri PT Dahana (Persero). Sebelumnya saya berkembang di PT Sigap Prima Astrea — mulai dari Security Guard, Admin Security Officer, CCTV Control Room Operator, hingga dipercaya sebagai PIC CCTV Control Room di lingkup industri PT Astra Daihatsu Motor.

Sebagai Control Room Officer, saya fokus pada monitoring CCTV, pengawasan situasi keamanan, komunikasi operasional, deteksi potensi risiko, serta pencatatan dan pelaporan kejadian. Setiap tugas menuntut ketelitian, kewaspadaan, respons cepat, dan koordinasi efektif untuk mendukung keamanan, keselamatan, serta kelancaran operasional perusahaan.
